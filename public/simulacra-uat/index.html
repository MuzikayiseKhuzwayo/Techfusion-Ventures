COMPREHENSIVE DEPLOYMENT GUIDE

Deploy the Next.js visual 16-bit RPG studio, headless Playwright runner, or Docker containers.

STEP 1

CLONE GUILD LAB & SETUP PYTHON ENVIRONMENT

Ensure Python 3.11+ and Node 20+ are installed on your workstation.

git clone https://github.com/MuzikayiseKhuzwayo/simulacra-uat-tester.git cd simulacra-uat-tester python -m venv venv # Windows: .\venv\Scripts\activate # Linux/macOS: source venv/bin/activate
STEP 2

INSTALL REQUIREMENTS & CHROMIUM BROWSER

Install all backend Python requirements and Playwright headless browser engines:

pip install -r requirements.txt playwright install chromium
STEP 3

INSTALL FRONTEND NEXT.JS 15 DEPENDENCIES

Install Next.js, React 19, and Tailwind CSS dependencies in frontend/:

cd frontend npm install cd ..
STEP 4

LAUNCH UNIFIED FULL STACK WITH ONE COMMAND

Launches FastAPI Backend (port 8000), Next.js RPG Studio (port 3000), and Demo Target (port 8585):

python run_dev.py
• Next.js 15 Town Canvas: http://localhost:3000
• FastAPI REST Docs: http://127.0.0.1:8000/docs
• Offline Target App: http://127.0.0.1:8585
CI/CD

GITHUB ACTIONS QUALITY GATE WORKFLOW

Drop .github/workflows/uat-simulacra.yml into your repo to block pull requests with low usability:

name: Simulacra UAT Autonomous Fleet on: [pull_request, push] jobs: simulation-gate: runs-on: ubuntu-latest steps: - uses: actions/checkout@v4 - name: Set up Python 3.11 uses: actions/setup-python@v5 with: python-version: '3.11' cache: 'pip' - name: Install Dependencies run: | pip install -r requirements.txt playwright install --with-deps chromium - name: Run 99 Automated Unit Tests run: pytest -v - name: Launch Headless Simulation Fleet run: | python -m src.simulacra.cli \ --url "http://localhost:3000" \ --goal "Browse catalog, add item to cart, and verify checkout" \ --personas 3 \ --title "PR Usability Gate" - name: Upload Audit Brief & Excel Workbooks uses: actions/upload-artifact@v4 with: name: uat-audit-report path: data/reports/
DOCKER

CONTAINERIZED DEPLOYMENT WITH DOCKER COMPOSE

Run Simulacra UAT inside isolated production containers:

version: '3.8' services: simulacra-api: build: context: . dockerfile: Dockerfile ports: - "8000:8000" environment: - ENVIRONMENT=production - DATABASE_PATH=/data/simulacra.db - HEADLESS=true volumes: - simulacra-data:/data simulacra-town-web: build: context: ./frontend dockerfile: Dockerfile ports: - "3000:3000" environment: - NEXT_PUBLIC_API_URL=http://simulacra-api:8000 depends_on: - simulacra-api volumes: simulacra-data:
docker compose up --build -d
