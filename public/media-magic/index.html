Deploy in seconds. Run anywhere.

Clone the repository from GitHub and launch the unified media manager locally or in the cloud. 

# 1. Clone repository from GitHub
git clone https://github.com/MuzikayiseKhuzwayo/mina-ai.git
cd mina-ai

# 2. Configure environment
copy .env.example .env
# Set OPENAI_API_KEY=sk-...

# 3. Start Unified Gateway (Port 8080)
python server.py

# 4. Start Next.js Studio Cockpit (Port 3000)
cd dashboard && npm install && npm run dev
